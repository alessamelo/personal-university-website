Optimization Methods

Instructor: Zenaida Castillo

In this course, I am learning how optimization methods can be used to find the best solution to a mathematical problem. We have studied the difference between minimization and maximization problems, as well as constrained and unconstrained optimization.

One of the topics I have found particularly interesting is using derivatives to find critical points. We analyze where the derivative becomes zero and then evaluate these points to determine whether they correspond to minimum or maximum values. We have also worked with gradients and how they can be used to optimize functions with more than one variable.

Main Topics

  • Numerical optimization
  • Minimization and maximization problems
  • Derivatives and critical points
  • Gradient-based optimization
  • Constrained and unconstrained problems
  • Linear optimization
  • Mathematical models

Topics I Expect to Learn

  • How to formulate optimization problems
  • How to find and evaluate optimal solutions
  • How to apply gradient-based methods to optimization problems

Intelligent Agents

Instructor: Tito Armas

In Intelligent Agents, I am learning how an agent interacts with an environment, observes its current state, and makes decisions based on the information available to it. We have studied the Markov property, which describes situations where the current state contains the relevant information needed to determine the next state, rather than requiring the complete history of previous states.

We have also worked with probability and state transitions to simulate how an environment changes over time. For example, we created simulations in which an agent or system moves between different states according to transition probabilities. We also worked on a dog training simulation to understand how an agent can learn or change its behavior depending on the current state and the action taken.

Main Topics

  • Intelligent agents
  • States and actions
  • Markov property
  • State transition probabilities
  • Markov decision processes
  • Reinforcement learning
  • Dynamic programming
  • Value functions and policies

Topics I Expect to Learn

  • How agents make decisions in an environment
  • How reinforcement learning can be used to train agents
  • How to design and evaluate agent policies

Scientific Communication Workshop

Instructor: Andres Tirado

This course focuses on the way scientific knowledge is communicated and shared. I am learning that scientific communication is not only about presenting information, but also about constructing clear arguments supported by evidence and communicating ideas to other members of the scientific community.

One important topic is the role of scientific publications. Research becomes part of the scientific community when its results are communicated through papers and other scientific publications. Because of this, we are learning about the organization of scientific papers, the purpose of their different sections, and how information and evidence should be presented.

We have also discussed communication processes, arguments, evidence, communication channels, and the difference between objective and subjective communication.

Main Topics

  • Scientific communication
  • Scientific publications
  • Organization of scientific papers
  • Arguments and evidence
  • Objective and subjective communication
  • Communication processes
  • Communication channels and codes

Topics I Expect to Learn

  • How to communicate scientific ideas clearly
  • How to organize and write scientific papers
  • How to construct arguments using appropriate evidence

Web Applications

Instructor: Francisco Hidrobo

In Web Applications, I have been learning the foundations of web development and how different technologies work together to create interactive websites. We started by learning HTML and its role in structuring the content of a webpage, and then moved on to CSS for styling and designing the interface.

We have worked with semantic HTML elements such as header, nav, main, section, article, and footer. We have also created webpages using links, images, lists, tables, forms, and different navigation elements. With CSS, I have been learning how to control layouts, colors, typography, spacing, borders, backgrounds, and responsive designs.

We have also started working with JavaScript to add functionality and interaction to webpages. More recently, we have been learning jQuery, a JavaScript library that simplifies many common tasks when working with HTML elements and events. Through these technologies, I am learning how a webpage can move from a static document to a more interactive and dynamic application.

Main Topics

  • HTML and semantic HTML
  • HTML document structure
  • Links and navigation
  • Images and multimedia
  • Lists and tables
  • HTML forms
  • Web servers and virtual hosts

Topics I Expect to Learn

  • How to develop complete web pages using HTML
  • How to style webpages using CSS
  • How to create more interactive web applications

A book I can use as an additional reference is HTML & CSS: Design and Build Websites by Jon Duckett.
