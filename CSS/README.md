# Personal University Website

This project is a personal university website created for educational purposes. It uses HTML and CSS to practice web development concepts and create a coherent personal website with a cozy pink visual style.

## Navigation

The website includes the following sections:

* **Home** — The main page with an introduction and personal information.
* **Courses** — A list of my university courses.
* **Schedule** — A table containing my current university schedule.
* **Hobbies** — Information about my hobbies and personal interests.
* **Illustration** — A collection of my current illustrations.
* **Contact** — A contact form created for educational purposes. It does not use a database or backend.

## Design
The website uses a consistent cozy and pink visual style across its pages. The design was created using CSS properties learned during the Web Applications workshop.

The project includes:

* Custom fonts
* CSS variables
* Flexbox
* Responsive styling
* Background images
* Custom navigation icons
* Colors, borders, shadows, and rounded elements
* Styled forms and tables
* Basic interactive effects such as hover states

The project focuses on applying fundamental CSS concepts to create a coherent visual identity rather than using advanced CSS frameworks or libraries.
