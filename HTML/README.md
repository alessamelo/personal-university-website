# Personal University Website

This project is a personal university website created for educational purposes. It consists of multiple HTML pages connected through navigation links.

## Navigation

The website includes the following sections:

* **Home** — The main page with personal and university-related information.
* **Courses** — A list of my university courses.
* **Schedule** — A table containing my current university schedule.
* **Hobbies** — Information about my hobbies and personal interests.
* **Illustration** — A collection of my current illustrations.
* **Contact** — A contact form created for educational purposes. It does not use a database or backend.

## HTML Features

The project demonstrates the use of several HTML elements and concepts, including:

* Multiple HTML pages
* Navigation between HTML documents using links
* `<a>` elements for navigation and references
* Tables for displaying the university schedule
* Forms for collecting contact information
* Images with appropriate `<img>` elements
* Lists for organizing information
* Headings and paragraphs for structuring content
* Semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`
